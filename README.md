# LUNÉA · этапы 1–6

Локальная основа приложения Windows 10/11 x64: Tauri 2, Rust, Vue 3, TypeScript, Vite, Tailwind CSS 4, Pinia, Vue Router и Lucide (@lucide/vue). Версии закреплены package-lock.json и Cargo.lock.

## Запуск

```powershell
npm install
npm run dev
npm run typecheck
npm run build
npm run tauri dev
npm run tauri build
```

Для нативных команд нужны Rust stable MSVC, Visual Studio C++ Build Tools, Windows SDK и WebView2. Установщик создаётся в src-tauri/target/release/bundle/nsis.

## Архитектура

- src/app/router.ts: hash-маршруты обзора, настроек и независимого /overlay.
- src/components/layout: оболочка основного окна; components/ui: масштабируемый лунный знак по мотивам референса.
- src/stores/theme.ts: четыре темы, проверка сохранённого значения, локальное сохранение, синхронизация через storage event.
- src/stores/audio.ts: реальные backend-снимки Core Audio, events, ожидающие записи и защита от старых ответов.
- src/services/preferences.ts: ограниченный доступ к локальным предпочтениям с обработкой ошибок хранилища.
- src/styles/main.css: семантические CSS-переменные, адаптивность и видимый клавиатурный фокус.
- src-tauri/src/audio: один COM MTA worker, устройства, endpoint volume, отдельные сессии и callbacks; src-tauri/src/desktop.rs: окна, трей, горячие клавиши и настройки.
- src-tauri/tauri.conf.json: main 1100×720, минимум 850×560; один overlay создаётся скрытым и повторно используется по фиксированной метке. Начальный размер 360×332, высота подстраивается под содержимое.
- src/assets/branding и mascot: оригинальные пользовательские референсы. Готовые пользовательские позы персонажа подключены в этапе 2; исходные изображения сохранены.

Core Audio подключён в этапе 4, реальная десктопная Яндекс Музыка через Windows GSMTC — в этапе 5. Discord управляется пользовательскими горячими клавишами на этапе 6; состояния Mute/Deafen неизвестны. Трей, глобальная горячая клавиша и always-on-top реализованы в этапе 3. Capabilities ограничены существующими окнами, событиями, проверяемыми настройками и узкими аудио/медиакомандами. Захвата звука/микрофона, произвольного filesystem/shell-доступа из JavaScript нет. Шрифты локальные; CSP ограничивает сетевые подключения.

## Кастомное окно · этап 1.5

`CustomTitleBar.vue` заменяет системный заголовок: свернуть, развернуть/восстановить, закрыть, переместить и изменить размер через Tauri Window API. Основное окно без decorations; его содержимое прокручивается независимо от панели, sidebar и footer. Скроллбар WebView2 — 6px, с цветом активной темы. `/overlay` остаётся независимым представлением без этой панели.

Подробности реализации, permissions, проверки и безопасные варианты решения ошибки 4551: [отчёт этапа 1.5](docs/stage-1.5.md).

## Готовый маскот LUNÉA

В интерфейс подключены восемь пользовательских прозрачных PNG. Именованные рабочие копии находятся в `public/mascot/poses/`; оригиналы сохранены рядом без изменений. Маскот реагирует на настоящий системный mute и музыку GSMTC; в настройках — задумчивая поза. Ошибка отправки Discord вызывает error; неподтверждённый Toggle не вызывает mute. Системный mute/нулевая громкость имеют приоритет sleeping над временными реакциями.

[Сопоставление исходных файлов, поведение и проверки WebView2](docs/mascot-integration.md).

## Компактный оверлей · этап 3

`Ctrl+D` показывает и скрывает оверлей. Сочетание, закрепление и автоскрытие меняются в настройках. Закрепление запрещает автоскрытие; режим поверх обычных окон включён всегда. Реальная громкость Windows, музыка GSMTC и результаты Discord-команд синхронизируются с главным окном. Все четыре темы и готовый маскот используются повторно.

Закрытие любого окна скрывает его. В трее доступны «Открыть LUNÉA», «Показать/скрыть оверлей», «Настройки» и «Выход». Только «Выход» завершает приложение. Повторный запуск возвращает существующее главное окно, не создавая второй процесс и иконку.

Настройки окон сохраняются в `%APPDATA%/app.lunea.audio/desktop.json`. [Отчёт этапа 3, изменения и проверки](docs/stage-3.md).

### Трей и автозапуск

Двойной левый клик по иконке трея восстанавливает главное окно; правый открывает меню. X прячет окно, «Свернуть» оставляет его в панели задач, «Выход» полностью завершает процесс.

В настройках добавлены «Запускать вместе с Windows» (по умолчанию выключено, официальный autostart plugin) и «Запускать свёрнутым в трей». Второй переключатель применяется только к автоматическому запуску с `--autostart`; ручной запуск всегда открывает main. Автозапуск включайте в установленной копии, поскольку регистрируется путь текущего exe. [Изменения и проверки дополнения](docs/tray-autostart.md).

## Windows Audio · этап 4

Главный экран управляет реальной громкостью/mute выхода Windows по умолчанию и отдельными аудиосессиями всех активных выходов. Разные сессии одного процесса не объединяются. Устройства ввода/вывода показываются с состоянием и default-ролями. Микрофоны доступны только для просмотра; default device меняется через стандартные параметры звука Windows.

Оверлей содержит настоящую общую громкость/mute и переход в полный микшер. Backend — единый источник аудиосостояния для двух окон; Core Audio callbacks и дополнительная сверка раз в 2 секунды поддерживают синхронизацию с внешними изменениями. В браузере настоящие аудиоконтролы недоступны.

[Полный отчёт, Windows API, файлы, реальные тесты и ручные проверки](docs/stage-4.md). Проверено на Windows 11/WebView2; Windows 10 отдельно не проверялась. Установщик x64 собран без изменения защиты Windows.

## Яндекс Музыка · этап 5

`src-tauri/src/media/` — отдельный WinRT MediaService. Проверенный на этом компьютере desktop source ID: `ru.yandex.desktop.music`. Реальные метаданные, обложка из thumbnail Windows, Play/Pause/Next/Previous и доступная перемотка поступают в оба окна через `lunea:media-state`. Громкость остаётся в Core Audio. Браузеры и другие источники не выбираются.

Выбор источника находится в настройках; в `%APPDATA%/app.lunea.audio/media.json` сохраняется только устойчивый source ID. Яндекс API, авторизация и внешняя загрузка обложек не используются. [API, изменённые файлы, результаты и ограничения](docs/stage-5.md).

## Discord · этап 6

`src-tauri/src/discord/` — отдельный DiscordService: проверка Stable/PTB/Canary по процессам и installation path, безопасные фиксированные SendInput-действия и события `lunea:discord-state`. Громкость/mute каждой выбранной Discord-аудиосессии использует прежний Core AudioService; это не Deafen.

Назначьте в Discord собственные Toggle Mute/Deafen, закройте страницу их настройки, затем укажите те же chords в Settings LUNÉA и подтвердите назначение. Поддерживаются Ctrl+Alt+Shift+F6–F11; два сочетания должны различаться и не конфликтовать с оверлеем. По умолчанию отправка выключена. Настройки без секретов сохраняются в `%APPDATA%/app.lunea.audio/discord.json`.

«Сочетание отправлено» означает вставку ввода Windows, а не достоверное состояние Discord. Подтверждённые mute/deafen в hotkey-режиме недоступны; Rich Presence не выдаётся за voice API. Никаких user tokens/self-bot/инъекций. [Исследование официальных API, файлы, реальные проверки и ограничения](docs/stage-6.md).

## Визуальное направление

Тёмная компактная аудиопанель: лунная волна, тонкие границы, спокойная Manrope с кириллицей, акцент по выбранной теме. Палитры взяты из задания; рекомендации ui-ux-pro-max применены к доступности и организации, без маркетинговых блоков из общего шаблона поиска.

## Стабильность и фон · этап 7

Сервисы Audio/GSMTC/Discord продолжают работать в трее. Скрытые WebView
сохраняют только последний снимок, при открытии сверяются с backend. Сверка
раз в 15 секунд восстанавливает потерянные события; повторяются только чтения,
никогда Toggle-команды. Старые ответы и повторные ревизии отбрасываются,
пропущенные временные реакции маскота при восстановлении не проигрываются.

Шрифты остаются локальными файлами под прежней CSP. Длинные имена устройств
переносятся внутри списка сессий. Темы, маскот и нативные интеграции сохранены.

Регрессионные frontend-тесты: `node --test tests/snapshotChannel.test.ts`.
Диагностика без дополнительных зависимостей проекта: `scripts/qa/stage7-*`.
Fixture `cargo run --manifest-path src-tauri/Cargo.toml --example hotkey_conflict`
резервирует Ctrl+Alt+F8 на 30 секунд без отправки ввода; в продукт не включается.

[Аудит, измерения, проверки и ограничения этапа 7](docs/stage-7.md).

## Фирменный установщик · этап 8

Один per-user NSIS пакет с original installer mascot, native dark pages, выбором
папки/ярлыков и opt-in запуска. Пользователь запросил только сборку: установка,
обновление и удаление не выполнялись. [Архитектура, проверки и ограничения](docs/stage-8.md).
Готовый файл: `src-tauri/target/release/bundle/nsis/LUNÉA_0.1.0_x64-setup.exe`.
Версия 0.1.0, x64, без цифровой подписи. Перед распространением нужны подпись и
install/update/uninstall matrix на безопасной машине. Автозапуск Windows не включается.

Для подготовки после изменений NSIS: `node scripts/installer/prepare-template.mjs`,
затем `npm run tauri build`. Artwork уже подготовлен и сохранён в installer/assets;
его пересоздание требует Python/Pillow и `scripts/installer/prepare-assets.py`.
