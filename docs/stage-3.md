# Этап 3 — компактный оверлей LUNÉA

## Реализовано

Один процесс Tauri содержит два окна: `main` и `overlay`. Оверлей создаётся один раз скрытым на маршруте `/overlay`, без главной навигации и CustomTitleBar. Закрытие кнопкой или Alt+F4 скрывает его, не уничтожая. Закрытие main тоже прячет приложение в трей; явный «Выход» сохраняет настройки, снимает горячие клавиши и вызывает `app.exit(0)`.

Оверлей без decorations, resizable:false, always-on-top и skip-taskbar. Начальный размер 360×332; ResizeObserver передаёт естественную высоту в ограниченную Rust-команду (300–440px). На текущем DPI фактическая высота обычно 335–336px. Прозрачные только внешние поля вокруг непрозрачной тематической карточки; скругление 16px, мягкая тень, без blur. WebView2 на текущей Windows корректно отрисовал прозрачный фон. Заголовок вызывает штатный Tauri `startDragging`, кнопки находятся вне области перетаскивания.

Содержимое: логотип, общая демогромкость, слайдер/mute, демотрек с предыдущим/следующим и play/pause, Discord Mute/Deafen, готовый MascotDisplay compact, закрепление, открытие main, скрытие. Подписи прямо обозначают демо. Системный звук, микрофон и Discord не меняются.

Используется существующая система тем. Pinia stores audio/demo сохранены; Rust владеет общим состоянием для двух окон. Клиенты отправляют только изменённые поля, слушают снимки с монотонной ревизией и игнорируют устаревшие ответы. Так изменение громкости не отправляет устаревшие значения трека или mute. Канальные деморегуляторы основного микшера остаются локальными — оверлей управляет только общей демогромкостью.

## Горячая клавиша, положение и настройки

- По умолчанию Ctrl+D через официальный `tauri-plugin-global-shortcut`, обработка только Pressed. Windows-реализация зависимости использует MOD_NOREPEAT.
- Сочетание меняется текстовым полем в настройках; нужны Ctrl или Alt. Пустые, некорректные, немодифицированные и Win/Meta-сочетания отклоняются.
- Семантически одинаковая комбинация не регистрируется повторно. Новое сочетание сначала регистрируется; лишь после успеха снимается старое. Конфликт сохраняет старую комбинацию и показывает объяснение. Конфликт при старте не мешает открыть оверлей из трея/настроек.
- Перед каждым показом сохранённая физическая позиция проверяется по полной рабочей области доступных мониторов, исключающей taskbar. При недоступной позиции выбирается правый край монитора главного окна, с отступом 16 логических px. Отрицательные координаты мониторов поддерживаются.
- Движение обновляет позицию в памяти. Положение сохраняется при скрытии, потере фокуса, сохранении настроек и явном выходе. После роста высоты видимое окно повторно проверяет доступную область.
- `pinned` запрещает автоскрытие; он не выключает always-on-top. `autoHide` сохраняется отдельно и применяется только без закрепления. Потеря фокуса подтверждается через 250ms и повторную проверку реального фокуса; ползунок и остальные элементы не прячут сфокусированное окно.
- `%APPDATA%/app.lunea.audio/desktop.json` содержит только shortcut/pinned/autoHide/position/theme. Запись через временный файл с заменой, ошибки сохранения видны в UI. Существующая тема из localStorage мигрирует в общий профиль, если в нём ещё нет темы. Демоданные и credentials не записываются.

## Трей и один экземпляр

Один TrayIconBuilder с id `lunea-tray` создаётся в Rust setup, а не в Vue/HMR. Меню: «Открыть LUNÉA», «Показать/скрыть оверлей», «Настройки», разделитель, «Выход». Первый официальный плагин — `single-instance`: второй запуск только показывает и восстанавливает существующее main.

«Настройки» отправляет адресное событие только в main. Подписка на навигацию тоже устанавливается только в main, поэтому оверлей не превращается в копию главного интерфейса. При быстром старте кешированного WebView раннее чтение состояния безопасно повторяется до завершения setup вместо вызова `state()` до `manage()`.

## Permissions

- `desktop-shared`: get_desktop_state, update_demo, set_desktop_theme, configure_overlay, open_main; только два локальных окна.
- `toggle-overlay`: только main, единственная команда toggle_overlay.
- `overlay-controls`: только overlay, hide_overlay и fit_overlay. Последняя дополнительно проверяет label и ограничивает размер в Rust.
- `core:window:allow-start-dragging`: только overlay. Существующие разрешения title bar main сохранены.
- `core:event:allow-listen/unlisten`: синхронизация, снятие обработчиков. Emit из JavaScript не включён.

Нет core:default, произвольного создания окон, raw global-shortcut IPC permissions, filesystem, shell, внешних origins, доступа к микрофону или устройствам. Rust сам сохраняет один фиксированный конфигурационный файл. Негативные native-проверки подтвердили запрет toggle_overlay из overlay и fit_overlay из main.

## Ограничения и непокрытые проверки

- Нативная иконка и отсутствие дублей подтверждены, состав меню и обработчики проверены по Rust. Автоматизированный клик по пунктам самого Windows notification-area меню, включая «Выход», не выполнен: доступная автоматизация не предоставила targetable окно taskbar. Поэтому это остаётся ручной проверкой, а не заявленным end-to-end тестом меню.
- Обработчик заголовка использует штатный startDragging. Автоматический drag помощника не передал наблюдаемое mousedown в WebView; реальное перемещение мышью этим прогоном не подтверждено и требует ручной проверки. Положение, восстановление невалидной позиции и геометрия проверены отдельно.
- Отдельная Windows 10, реальные несколько мониторов/DPI-переходы и игры в эксклюзивном fullscreen не проверялись. Работа поверх эксклюзивного fullscreen не гарантируется.
- Установщик собран, но установка и цифровая подпись не выполнялись. Системная защита и политики Windows не менялись; по одному успешному прогону нельзя утверждать, что Code Integrity 4551 устранена навсегда.

Артефакт: `src-tauri/target/release/bundle/nsis/LUNÉA_0.1.0_x64-setup.exe`. Запуск разработки: `npm run tauri dev`. При уже работающем экземпляре второй exe возвращает существующее главное окно.

## Для этапа 4

Остаются реальные интеграции по отдельному заданию: Windows Core Audio и устройства, GSMTC/музыка, Discord RPC и фактический mute/deafen. Сейчас в этих областях только помеченные демоданные. Нативный каркас окон, трея, сочетаний и синхронизации подготовлен. К этапу 4 автоматически не переходили.

Реализация опирается на официальные API: [Global Shortcut](https://v2.tauri.app/plugin/global-shortcut/), [Single Instance](https://v2.tauri.app/plugin/single-instance/), [System Tray](https://v2.tauri.app/learn/system-tray/), [Monitor/work_area](https://docs.rs/tauri/latest/tauri/window/struct.Monitor.html).
