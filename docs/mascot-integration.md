## Компонент и поведение

- `src/components/ui/MascotDisplay.vue`: обычный `<img>`, `state` из восьми состояний, `size` = compact / medium / large, `animated` (по умолчанию true), `alt` с осмысленным описанием каждой позы по умолчанию. Размеры до 128 / 220 / 400px, `object-fit:contain`, фиксированная пропорция исходника. Base64 и фильтров перекраски нет. Ошибка загрузки показывает доступное текстовое сообщение.
- `src/types/mascot.ts`: типы, реальные URL, описания и подписи восьми поз.
- `src/stores/demo.ts`: только визуальные демоданные музыки/Discord; состояние не сохраняется и не вызывает системные/сетевые API. Нажатие «Слушать демо» не воспроизводит звук.
- `src/composables/useMascotReactions.ts`: один владелец реакций в основном layout. Welcome — 3,5с при создании главной страницы; next — 1,8с; error — 3,5с; idle после 45с без действий. Воспроизведение показывает listening; выключение звука или громкость 0 — sleeping; демо Discord Mute — mute; настройки — curious.
- Приоритет постоянных состояний: настройки → выключенный звук → Discord Mute → отсутствие активности → воспроизведение/ожидание. Временная реакция покрывает базовое состояние. Действие, меняющее базовое состояние, отменяет временные реакции. Наложенные временные реакции возвращают предыдущую ещё не истёкшую реакцию; после завершения возвращается актуальное базовое состояние.
- Все таймеры очищаются при размонтировании. Переход на `/overlay` уничтожает владельца реакций; возвращение создаёт его заново. Существующий оверлей не менялся — компактный размер компонента подготовлен для будущего этапа.
- `src/styles/mascot.css`: отдельная широкая композиция на главной, мягкий тематический фон без окрашивания персонажа, адаптивные размеры, короткая смена поз и поддержка prefers-reduced-motion. Настройки содержат отдельное medium-изображение.

Дополнительно изменены `src/components/layout/MainLayout.vue`, `src/views/DashboardView.vue`, `src/views/SettingsView.vue`, `src/main.ts`. Новых npm/Rust-зависимостей и Tauri permissions нет.

## Проверки

- `npm run typecheck` и `npm run build`: успешно.
- Debug Tauri успешно запущен с настоящим WebView2; Playwright подключён по локальному CDP только на время тестирования. Параметры отладки не сохранены в конфигурации приложения.
- На 1100×720: все 8 поз × 4 темы = 32 проверки реальных изображений. Для каждой подтверждены загрузка 1346×1168, object-fit contain, отсутствие CSS-фильтра, отсутствие обрезания изображения областью прокрутки и горизонтального переполнения.
- Отдельное нативное окно с параметрами Tauri 850×560: ещё 32 проверки всех поз во всех темах. При текущем DPI Windows 125% WebView2 округлил viewport до 851×560; это зафиксировано в результатах. Эмуляция браузерного viewport вместо окна не применялась. Итого — 64 проверки. Тестовый override размера находится только в исключённом из Git `output/mascot/qa-850.json`, основная конфигурация Tauri не менялась.
- Через реальные элементы управления проверены welcome, listening, sleeping, curious, mute, next, error, idle. После next/error восстанавливается listening. Ошибок JavaScript/console и неудавшихся запросов изображений нет.
- Отдельно проверены таймеры с управляемыми часами Playwright в WebView2: наложенные error/next, отмена реакции при mute, idle через 45с, переход в настройки, размонтирование на overlay и повторное создание. Переходы корректны, просроченная реакция не возвращается.
- Результаты и снимки: `output/mascot/` (исключены из Git).

## Границы этапа

Не добавлены Windows Audio, GSMTC, Яндекс Музыка, Discord RPC, трей или горячие клавиши. Release-сборка в этом задании не запускалась: предыдущее ограничение Windows Code Integrity (4551) не обходилось. Исходный размер main 1100×720 и минимум 850×560 сохранены.
